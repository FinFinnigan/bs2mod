# MASTER-SPEC — BoyShop / BS2Mod

BoyShop/BS2Mod is a reusable **modular no-code ecommerce website builder** with BoyShop as its first real template and implementation.

A non-technical Superadmin must ultimately configure the supported customer journey without editing source code:

**landing/home → navigation → content pages → categories/collections → product listing → product detail → cart → checkout → confirmation/success**

The current approved BoyShop storefront must remain recoverable and become the first reusable template.

Normal supported configuration should use validated contracts for site identity, templates, themes, navigation, pages, sections, catalog/cart/checkout presentation, provider settings, draft/published state, and deployment/domain guidance where supported.

No-code flexibility must never bypass authorization, totals/pricing validation, inventory, checkout validation, payment validation, order-state rules, server-side validation, provider safety, secrets, or publish permissions.

The setup wizard must orchestrate the same configuration model, not create a second parallel system.

Target editing model:

**Edit → Save Draft → Preview → Publish**

The product is not complete merely because ecommerce works. Final acceptance requires evidence that a non-technical Superadmin can perform the supported landing-to-checkout setup without source-code edits while protected commerce/security rules remain intact.

All delivery uses tiny chunks.
