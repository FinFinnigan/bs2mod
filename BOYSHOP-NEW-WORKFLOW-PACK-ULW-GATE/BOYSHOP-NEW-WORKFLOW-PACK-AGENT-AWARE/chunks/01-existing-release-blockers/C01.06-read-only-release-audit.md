# C01.06 - Read-only release audit

## Outcome

Produce a findings list describing the current release readiness of this fork using only checks that need no purchased domain, no live Mollie key, and no deploy.

## Scope

Audit only, using the local repository and already-known facts:

- Verify the repository HEAD commit and that the working tree is clean.
- Run `npm run typecheck`, `npm run lint`, `npm test`, and `npm run build`.
- Verify the OpenNext/Cloudflare bundle build still succeeds.
- Confirm `MOLLIE_ALLOW_LIVE` is still absent from `wrangler.jsonc` and `.env.local`.
- Report the residual state of blockers B3, B5, and B6.

Strictly forbidden in this chunk:

- Buying, registering, or transferring a domain, or connecting one to Cloudflare.
- Creating, editing, or deleting DNS records, Cloudflare zones, or Worker custom domains.
- Deploying anything or running any deploy command.
- Adding, changing, or removing any secret or binding.
- Setting or removing `MOLLIE_ALLOW_LIVE`.
- Running any live payment transaction.
- Any database write, migration, or schema change.
- Modifying source files, evidence documents, or workflow pack control documents.

## Completion

The audit produces a findings list. It does not by itself clear any blocker: B3, B5, and B6 stay open until the owner supplies the external facts or performs the paid actions they depend on.
