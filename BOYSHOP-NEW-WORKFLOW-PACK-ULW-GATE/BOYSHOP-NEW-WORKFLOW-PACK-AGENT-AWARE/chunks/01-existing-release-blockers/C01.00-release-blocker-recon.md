   Push state is **not** a blocker and must not be re-raised as one: `BS2Mod-site` is fully pushed and in sync with `origin/main` (HEAD `70d10f8` = live remote `main`, verified 2026-09-30). `C:\dev` is a separate repository for unrelated projects, contains zero `BS2Mod-site` files, and is **out of scope** for this plan.

4. Order the blockers by dependency (what must close before what) and write the result into `IMPLEMENTATION-MAP.md` as the phase-01 evidence entry.
5. Generate only the tiny phase-01 chunks that repository evidence actually justifies. Do not pre-generate guesses.
