# MODEL-ROUTING — Model and Execution Guidance

## Default
Prefer the user's normal/default Big Pickle configuration for routine tiny chunks.

## Escalate only when justified
Recommend ULW / DeepSeek for genuinely difficult cross-layer reasoning, architecture, security, migration/data-integrity planning, or complex release reconciliation.

Do not silently switch.

Use:
`MODEL ADVISORY — ULW/DeepSeek recommended`
with one short reason if needed.

## Sisyphus
Sisyphus is an execution/orchestration choice. Recommend it only for chunks that genuinely need coordinated investigation/orchestration.

Use:
`EXECUTION ADVISORY — Sisyphus recommended`
with one short reason if needed.

## Scope
Stronger models or agents never expand the active chunk's authorization.
